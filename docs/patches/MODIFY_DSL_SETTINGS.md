# Extend DSL settings
This patch extends the DSL noise immunity.<br>

[![screenshot](../screenshots/000-OTH_MODIFY_DSL_SETTINGS_md.png)](../screenshots/000-OTH_MODIFY_DSL_SETTINGS.png)

4 "Performance" levels are added to the 4 "Stability" levels.

 * On some FRITZ!Boxes the upload cannot be changed and jumps back to the default after clicking "Apply".
 * On many beta/labor/inhouse firmwares none of the values can be changed and they jump back to the default after clicking "Apply".
