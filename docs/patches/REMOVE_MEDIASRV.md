# Remove mediasrv (UPnP/DLNA)
Removes the AVM media server.<br>
<br>

For the local network this is a questionable matter on most boxes anyway - after all, they only have USB 1.1 for connecting storage media,
which makes access correspondingly slow. If the media are available in better quality, "stuttering" is certainly already pre-programmed.
Not without reason AVM equipped its stand-alone media server (see link) with USB 2.0.
