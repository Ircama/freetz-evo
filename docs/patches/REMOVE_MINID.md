# Remove minid (Fritz!Mini and MT-D/F)
Removes support for FritzMini.<br>
<br>

FritzMini is a WLAN multimedia device from AVM GmbH that is used both as a VoIP client and as a client for web radio, podcasts, streaming from the media server, and more.
