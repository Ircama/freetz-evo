# xtrans 1.5.2
  - Package: [master/make/libs/xtrans/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/xtrans/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: X transport layer abstraction headers
  - Used by: `libX11`
  - Externalization: not supported (build-time only)

xtrans provides the X transport layer abstraction used by libX11, including support for Unix domain sockets, TCP/IP, and other transport mechanisms. Build-time only.
