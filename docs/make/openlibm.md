# openlibm
  - Homepage: [https://openlibm.org/](https://openlibm.org/)
  - Repository: [https://github.com/JuliaMath/openlibm](https://github.com/JuliaMath/openlibm)

openlibm is a portable standalone C math library designed for consistent libm behavior across platforms.

## Typical consumers

- software stacks that require a predictable math runtime

## Notes

In Freetz-EVO this package is mainly a dependency/runtime library.
