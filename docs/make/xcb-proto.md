# xcb-proto 1.17.0
  - Package: [master/make/libs/xcb-proto/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/xcb-proto/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: XML-XCB protocol descriptions and Python code generator
  - Used by: `libxcb`
  - Externalization: not supported (build-time only)

xcb-proto provides the XML protocol description files for the XCB (X C Bindings) library, along with the Python code generation tools used to produce the XCB C bindings.
