# krb5 (MIT Kerberos runtime libs)

- Homepage: https://web.mit.edu/kerberos/
- Changelog: https://github.com/krb5/krb5/releases
- Repository: https://github.com/krb5/krb5
- Package: ../../make/libs/krb5/

This package exports MIT Kerberos runtime libraries used by target-side software
that needs Kerberos/GSSAPI integration (for example LDAP-dependent features).

Provided target libraries include:

- `libkrb5`
- `libgssapi_krb5`
