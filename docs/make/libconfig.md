# libconfig

  - Package: [master/make/libs/libconfig/](https://github.com/Ircama/freetz-evo/tree/master/make/libs/libconfig/)
  - Provides: `libconfig.so`
  - Used by: `shairport-sync`

`libconfig` is a compact C library for reading and writing structured configuration files. In this tree it is part of the `shairport-sync` runtime stack, where it backs the native `shairport-sync.conf` format generated by Freetz.
