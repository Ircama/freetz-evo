# libxcb 1.17.0
  - Package: [master/make/libs/libxcb/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/libxcb/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: `libxcb.so` — X C Bindings (XCB) protocol library
  - Used by: `libX11`
  - Externalization: supported

XCB (X C Bindings) is a replacement for the traditional Xlib, providing a smaller, more efficient C interface to the X11 protocol with better threading support.
