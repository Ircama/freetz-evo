exfatprogs provides user-space utilities for exFAT filesystem creation,
consistency checks, labels, and tuning operations.

Typical tools included by this package:

- `mkfs.exfat`: create exFAT filesystems
- `fsck.exfat`: check and repair exFAT filesystems
- `exfatlabel`: read or set exFAT volume labels
- `tune.exfat`: tune selected exFAT filesystem parameters
