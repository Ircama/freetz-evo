The **[VPNC client](http://www.vpnc.org/)** is
an open-source alternative to the Cisco VPN client and is used to create
Virtual Private Network
([VPN](http://de.wikipedia.org/wiki/Virtual_Private_Network))
connections. It transfers all outgoing network connections over the
internet in encrypted form to another computer. That computer then
forwards them as if they originated there. This allows data that is
accessible in a company network only from the local network to be reached
as if you were directly connected to that network.
