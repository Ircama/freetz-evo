# libvorbis / libvorbisfile

  - Package: [master/make/libs/libvorbis/](https://github.com/Ircama/freetz-evo/tree/master/make/libs/libvorbis/)
  - Provides: `libvorbis.so`, `libvorbisenc.so`, `libvorbisfile.so`
  - Used by: `cmus`

`libvorbis` supplies the Xiph.Org Vorbis runtime stack. `cmus` uses the high-level `libvorbisfile` layer for Ogg Vorbis decoding.
