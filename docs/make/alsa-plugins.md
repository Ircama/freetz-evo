# alsa-plugins 1.2.12

  - Homepage: [https://www.alsa-project.org/](https://www.alsa-project.org/)
  - Provides: ALSA output and conversion plugins (samplerate, speexrate, lavrate, etc.)
  - Used by: —
  - Externalization: supported

ALSA plugins provides additional PCM and rate converter plugins for the ALSA sound system. Includes the samplerate (libsamplerate), speexrate (libspeex), and lavrate (FFmpeg) rate converters.
