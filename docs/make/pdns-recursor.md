# pdns-recursor 5.3.4

- Homepage: https://www.powerdns.com/recursor.html
- Changelog: https://doc.powerdns.com/recursor/changelog/
- Repository: https://github.com/PowerDNS/pdns
- Package: ../../make/pkgs/pdns-recursor/

pdns-recursor packages the PowerDNS Recursor resolver daemon for freetz targets.

It is provided as a separate package from pdns-authoritative and pdns-dnsdist,
following upstream project split.
