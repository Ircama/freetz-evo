# json-c 0.17
  - Homepage: [https://json-c.github.io/json-c/](https://json-c.github.io/json-c/)
  - Repository: [https://github.com/json-c/json-c](https://github.com/json-c/json-c)

json-c is a lightweight C library for JSON parsing, manipulation, and serialization.

## Typical consumers

- ttyd and other modern C daemons
- tools exposing JSON config/status interfaces

## Notes

This is typically used as a shared dependency package.
