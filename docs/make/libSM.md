# libSM 1.2.4
  - Package: [master/make/libs/libSM/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/libSM/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: `libSM.so` — X Session Management library
  - Used by: `libXt`
  - Externalization: supported

libSM is the X Session Management library from X.org. It provides the protocol for session management in the X Window System, allowing applications to save and restore their state.
