# xorgproto 2024.1
  - Package: [master/make/libs/xorgproto/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/xorgproto/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: X11 protocol header files and specifications
  - Used by: All X11 libraries
  - Externalization: not supported (build-time only)

xorgproto provides the combined X11 protocol header files, replacing the older separate protocol header packages (xproto, kbproto, etc.). It is a build-time dependency only.
