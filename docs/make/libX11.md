# libX11 1.8.10
  - Package: [master/make/libs/libX11/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/libX11/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: `libX11.so` — Core X11 protocol client library
  - Used by: All X11-based applications and toolkits
  - Externalization: supported

libX11 is the core X11 protocol client library from X.org. It provides the C API for interacting with an X Window System display server, including window management, events, graphics operations, and color management.
