# libcares (c-ares)
  - Homepage: [https://c-ares.org/](https://c-ares.org/)
  - Repository: [https://github.com/c-ares/c-ares](https://github.com/c-ares/c-ares)

libcares is an asynchronous DNS resolver library for event-driven applications.

## Typical consumers

- aria2
- curl-related stacks and network daemons needing async DNS

## Notes

This package is normally consumed as a dependency.
