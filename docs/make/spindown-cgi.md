# spindown-cgi
  - Package: [master/make/pkgs/spindown-cgi/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/pkgs/spindown-cgi/)
  - Steward: -

With **Spindown**, compatible *"mechanical"* hard disks can be put into
sleep mode.

[![spindown-cgi](../screenshots/69_md.png)](../screenshots/69.png)

**Start type**: Automatic (when the box starts) or manual (start the
service by hand).
**Device names**: The device name of the hard disk that should be put to
sleep is entered here (sda, sdb, sdc, etc.).
**Idle time**: After the idle time configured here has elapsed, the hard
disk is put to sleep.
**Mode**: Standby or Sleep: simply try which mode can put the hard disk
into idle state and wake it up again.
