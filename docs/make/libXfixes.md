# libXfixes 6.0.2

  - Provides: `libXfixes.so` — X11 fixes extension library
  - Used by: `libXi`
  - Externalization: supported

libXfixes provides client-side support for the XFIXES extension, which adds protocol-level fixes and improvements, including region handling, pointer barriers, and selection tracking.
