# libmad

  - Package: [master/make/libs/libmad/](https://github.com/Ircama/freetz-evo/tree/master/make/libs/libmad/)
  - Provides: `libmad.so`
  - Used by: `cmus`

`libmad` is the fixed-point MPEG audio decoder used by `cmus` for MP3 playback. It is especially suitable for MIPS targets without native floating-point hardware.
