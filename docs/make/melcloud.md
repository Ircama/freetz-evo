# melcloud (freetz package)

- Homepage: https://www.melcloud.com/
- Package: ../../make/pkgs/melcloud/

melcloud provides a lightweight target daemon and CGI/web integration to interact
with Mitsubishi Electric MELCloud-connected devices from freetz.

The package includes:

- runtime config under `/mod/etc/default.melcloud/`
- init script `rc.melcloud`
- CGI endpoint and web UI page
- helper CLI source for device interaction
