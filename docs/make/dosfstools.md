dosfstools provides core utilities for FAT filesystems and is commonly used
for flash/USB storage setup and diagnostics.

Typical tools included by this package:

- `mkfs.fat`: create FAT filesystems
- `fsck.fat`: check and repair FAT filesystems
- `fatlabel`: read or set FAT volume labels
