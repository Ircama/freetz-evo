# libzen
  - Homepage: [https://mediaarea.net/MediaInfo/Support/SDK](https://mediaarea.net/MediaInfo/Support/SDK)
  - Repository: [https://github.com/MediaArea/ZenLib](https://github.com/MediaArea/ZenLib)

libzen (ZenLib) is a utility/support C++ library used primarily by the MediaInfo stack.

## Typical consumers

- mediainfo
- libmediainfo

## Notes

This is primarily a dependency package and is usually not used directly by command-line users.
