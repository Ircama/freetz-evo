# ncursesw

  - Package: [master/make/libs/ncursesw/](https://github.com/Ircama/freetz-evo/tree/master/make/libs/ncursesw/)
  - Provides: `libncursesw.so` and wide-character curses companion libraries
  - Used by: `cmus`

`ncursesw` is the wide-character variant of ncurses. It provides the terminal UI layer for `cmus`, including Unicode-capable text rendering and the usual curses abstractions.
