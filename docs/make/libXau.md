# libXau 1.0.11
  - Package: [master/make/libs/libXau/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/libXau/)

  - Provides: `libXau.so` — X11 authorization handling library
  - Used by: `libxcb`, `libX11`
  - Externalization: supported

libXau is the X11 authorization protocol library, handling MIT-MAGIC-COOKIE-1 and other authorization mechanisms for X server connections.
