gptfdisk provides GPT-aware partitioning and recovery tools.
It complements classic fdisk-like workflows with GPT-specific operations.

Typical tools included by this package:

- `gdisk`: GPT fdisk interactive utility
- `cgdisk`: curses-based GPT partition editor
- `sgdisk`: scriptable GPT partition manipulator
- `fixparts`: convert/repair damaged MBR partition tables
