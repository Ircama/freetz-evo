# libwebsockets 4.3.9
  - Homepage: [https://libwebsockets.org/](https://libwebsockets.org/)
  - Repository: [https://github.com/warmcat/libwebsockets](https://github.com/warmcat/libwebsockets)

libwebsockets is a C library implementing WebSocket and related HTTP protocols.

## Typical consumers

- ttyd
- websocket-enabled daemons and embedded web services

## Notes

In Freetz-EVO this package is generally selected as a dependency by higher-level tools.
