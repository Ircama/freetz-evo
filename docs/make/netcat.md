**[netcat](http://netcat.sourceforge.net/)** is
a simple tool for transporting data from standard input or output over
network connections. It operates as a client or server using the
[TCP](http://de.wikipedia.org/wiki/Transmission_Control_Protocol)
and
[UDP](http://de.wikipedia.org/wiki/User_Datagram_Protocol).
protocols. The man page calls it the TCP/IP Swiss army knife.

The [socat](socat.md) package provides an alternative to *netcat*.
