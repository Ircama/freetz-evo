# libdaemon

  - Package: [master/make/libs/libdaemon/](https://github.com/Ircama/freetz-evo/tree/master/make/libs/libdaemon/)
  - Provides: `libdaemon.so`
  - Used by: `shairport-sync`

`libdaemon` is a lightweight helper library for UNIX daemons. `shairport-sync` uses it for daemonisation and PID-file related runtime support in the embedded build.
