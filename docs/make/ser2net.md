ser2net publishes a local serial interface on the network via Telnet.<br>

Usage examples:

  - [http://www.nwlab.net/tutorials/ser2net/konsolenserver-linux.html](http://www.nwlab.net/tutorials/ser2net/konsolenserver-linux.html)
  - [http://www.aufpreis.de/aufpreis/php/ser2netttyredirect.php](http://www.aufpreis.de/aufpreis/php/ser2netttyredirect.php)

As a Windows client, [HW Virtual Serial Port](http://www.hw-group.com/products/hw_vsp/index_de.html) is suitable.
Direct access via Telnet to ser2net's network port is also possible.
