# pdns-dnsdist 1.9.7

- Homepage: https://www.dnsdist.org/
- Changelog: https://doc.powerdns.com/dnsdist/changelog/
- Repository: https://github.com/PowerDNS/pdns
- Package: ../../make/pkgs/pdns-dnsdist/

dnsdist is the DNS load-balancer/front-end from the PowerDNS project.

This package builds target-side dnsdist binaries for policy routing, load balancing,
and DNS traffic filtering in front of authoritative/recursive servers.
