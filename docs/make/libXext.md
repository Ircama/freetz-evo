# libXext 1.3.6
  - Package: [master/make/libs/libXext/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/libXext/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: `libXext.so` — X11 protocol extensions library
  - Used by: `libXi`, `libXmu`
  - Externalization: supported

libXext provides the common base for X11 protocol extensions, including SHAPE, MIT-SHM, DPMS, and other extension protocols used by X11 applications.
