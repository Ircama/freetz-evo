# util-macros 1.20.2
  - Package: [master/make/libs/util-macros/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/util-macros/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: Autoconf/automake macros for X.org packages
  - Used by: `xorgproto`, `xcb-proto`, `xtrans`, all X11 libraries
  - Externalization: not supported (build-time only)

util-macros provides a collection of autoconf/automake m4 macros used by X.org packages. It is a build-time dependency only, not installed on the target.
