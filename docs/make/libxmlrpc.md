# libxmlrpc
  - Homepage: [https://xmlrpc-c.sourceforge.io/](https://xmlrpc-c.sourceforge.io/)
  - Project page: [https://sourceforge.net/projects/xmlrpc-c/](https://sourceforge.net/projects/xmlrpc-c/)

libxmlrpc provides XML-RPC client/server facilities used by software that exposes RPC control APIs.

## Typical consumers

- rtorrent/rutorrent integration paths relying on XML-RPC/SCGI workflows

## Notes

This is mainly a runtime dependency package.
