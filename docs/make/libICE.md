# libICE 1.1.1
  - Package: [master/make/libs/libICE/](https://github.com/Freetz-NG/freetz-ng/tree/master/make/libs/libICE/)
  - Homepage: [https://www.x.org/](https://www.x.org/)
  - Provides: `libICE.so` — Inter-Client Exchange library
  - Used by: `libSM`, `libXt`
  - Externalization: supported

libICE is the Inter-Client Exchange library from X.org. It provides a framework for inter-client communication in the X Window System, used by session management and other X11 protocols.
